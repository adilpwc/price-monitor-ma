# Sécurité

Signalez les vulnérabilités en privé via GitHub Security Advisories. Ne créez pas d'issue publique contenant un secret ou une preuve d'exploitation. Révoquez immédiatement tout token Telegram exposé. Les secrets requis sont exclusivement `TELEGRAM_BOT_TOKEN` et `TELEGRAM_CHAT_ID`, stockés dans GitHub Actions Secrets.
